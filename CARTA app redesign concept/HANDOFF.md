## The concept (do not drift)

The lot of green coffee and the road that connects it to the cup. Core laws: the atlas is everyone's, the record is yours (personal scores/brews never averaged into the shared page); never print a number that lied (scores travel with protocol + grader; "unread" is a state, never a low default); resolution is stated, never rounded up; authority is scoped to your own link (the roaster owns the roast, never the farm; the road is compiled, not owned); every mark explains itself one tap away (the primer-sheet pattern — add terms there, never inline tooltips); one ember per screen; voice is quiet, declarative, no exclamation, no gamification, no emoji.

## Architecture

Single DC, one screen-state machine: `state.screen` ∈ today · atlas · lot · roaster · cafe · brew · **shelf** · **homecup** · cuplog · propose · record · more · notes, with **`state.lotKey` · `roasterKey` · `cafeKey`** selecting the three parameterised detail screens. Tabs: **Today · Atlas · Record · More** — **brew/shelf/homecup ride off Today** (all four light the Today tab); lot/roaster/cafe/cuplog/propose ride off Atlas. 480px column, sticky header + tab bar, `data-screen-label` on every wrapper. `go(s)` resets scroll (window + main); `openLot/Roaster/Cafe(k)` and `pickBrew(k)` do the same. **Primers**: `PR` map (term → {t,b}); `ex.<key>` opens the primer sheet, auto-generated from `PR` keys — a new `PR` entry wires its `ex` for free.

**Motion** — the one sanctioned non-inline CSS, in `<helmet><style>`: `:root` tokens (`--mo-fast/base/considered/ease`), `@keyframes` (`ca-rise`, `ca-settle`, `ca-pins-in`, `ca-draw`), the animation classes (`.ca-screen`, `.ca-sheet`, `.wc-rise`, `.ca-map.is-reading .ca-season-line/.ca-pin-layer`), and the `prefers-reduced-motion` block. Everything else stays inline; a few inline `transition:` declarations reference the tokens (e.g. the season button). `reduceMotion()` helper reads the `reduceMotion` prop OR the OS query.

**Sheets — fixed layers, kept distinct:** confirm/read-back **and What's New** (backdrop z-36 / sheet z-38, mutually exclusive) · claim (z-42/44) · primer (z-40/50, stacks above any) · welcome overlay (z-120). All sheets carry `class="ca-sheet"` for tokenised rise + reduced-motion stilling.

**The home-cup arc**: `BREW_COFFEES` (worka/kia/ilusion → name/short/roaster/origin/resolution) drives shelf + brew hero + home-cup context. `state.setup {grinder,brewer,scale}` + `setupEditing`; `state.brewCoffee`/`brewFrom` (`today`|`shelf`) drive the brew back-target; `state.homeScore`/`homeDescs`/`homeLine` mirror `cupScore`/`cupDescs`/`cupLine`. The old brew-embedded cup (`hedonic`/`descs`/`saveBrew` vals) is dead — the home Cup is its own screen.

**The interlude**: `state.season`, `readSeason()` (reduce-motion → `'read'` immediately; else `'reading'` then `'read'` after 980ms), `atlasReadingCls`/`seasonShown`/`seasonIdle`/`seasonDone`; the season line is an inline `<svg viewBox="0 0 100 100" preserveAspectRatio="none">` with a `.ca-season-line` path styled entirely in the helmet class (only `class`+`d` on the element, so no camelCase-attribute risk).

**Export / import** unchanged: `downloadLedger`, `renderLedgerHtml` (pure `data→HTML`, `</script>` built from fragments), `readLedgerFile`, `parseLedger`. `ledgerData` built once in `renderVals` from `READINGS`+`RECORD`+`LOT_PAGES` overlays + `CAFES` cups + `s.signed`/`s.corrections`. **Any HTML built as a string must guard its `</script>`.** Themes paper/dusk via `data-theme`; each café carries a paper/dusk palette pair (the one sanctioned colour override). Tweaks props: `theme`, `showWelcome`, **`reduceMotion`**.

A file the app *writes out* to stand alone (the export) inlines real token hexes; that's the sanctioned exception, not licence to hardcode colour in the app. Small targeted edits over forks (fork to `CARTA Redesign v2.dc.html` only for a structural rework). Keep one ember per screen and the score/overlay as the reader's own — never merge or average into the shared page. Keep fixtures consistent (three lots, three roasters, four cafés). Hold each surface to the brief's judgement gate (would a Sey/Coffee Collective devotee assume it costs money and respects them; does it work at 7am, in dusk, offline; read the copy aloud; ember spent exactly once; could the number defend how it got there; is the empty state as designed as the full one).
